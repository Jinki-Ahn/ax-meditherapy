# 베이스캠프 루프 (BaseCamp Loop) — 시딩을 매주 반복되는 인과 실험으로 바꾸는 운영 플러그인 (메디테라피)

닫힌 고밀도 커뮤니티(1호: 군 장병)를 자연 실험장으로 삼아 시딩 → 검색 리프트 → 재구매의 인과를 주 단위로 실측하고, 증명된 패턴을 다음 커뮤니티로 복제하는 시딩 운영 엔진이다. 관찰 데이터에서 인과를 추출하는 대신, 시딩을 처음부터 처치/대조와 고유 추적 코드가 있는 실험으로 설계해 추정이 아니라 측정을 한다. 이 저장소는 그 온톨로지(4개 엔티티)와 5단계 파이프라인, 그리고 "루프가 학습하는 구조인가"를 실측하는 검증 하네스의 구현이다.

## 구조

```
src/skills/medi-agent/
├── data/
│   ├── ontology/
│   │   ├── schema.json          # 온톨로지 스키마(v0.4): 커뮤니티·크리에이터·제품·전환 신호
│   │   ├── seed.json            # 소형 예시 인스턴스(스키마 적합)
│   │   └── ONTOLOGY.md          # 설계 노트: 필드별 기획서 근거, 추가 제안의 판정 기록
│   ├── mock/
│   │   ├── mock_data.json       # 모의 데이터(크리에이터 30 × 커뮤니티 12, 생성기 산출물)
│   │   └── mock_data_edge.json  # 적대 데이터셋(배정 전면 불가·홀수 쌍·신호 부재)
│   └── verification/
│       └── report.md            # 검증 하네스 실측 리포트(문항 5의 근거 수치)
└── scripts/
    ├── generate_mock_data.py    # 모의 데이터 생성기(--seed 재현 가능)
    ├── validate_ontology.py     # 온톨로지 구동 검증(6개 검사)
    ├── pipeline.py              # 5단계 파이프라인 본체
    ├── signal_adapter_mock.py   # 모의 신호 어댑터(실서비스에서 교체되는 유일한 층)
    ├── test_decision_coverage.py# 결정 커버리지 테스트 스위트(20+케이스)
    └── verify_harness.py        # 검증 하네스(인과 검출·CPA·프록시 보정 실측)
```

## 파이프라인 (5단계)

입력은 온톨로지(후보 크리에이터·커뮤니티·제품·신호 정의)와 예산, 출력은 실험 설계·브리프·수요 증거 패키지·차주 예산 재배분이다.

1. **온톨로지 로드** — 스키마 검증 후 4개 엔티티와 루프 상태(조합 스코어)를 읽는다.
2. **실험 설계(처치 이원화)** — 유사 PX 지점 쌍 안에서 처치/대조를 배정하고, 전국 도달 크리에이터는 게시 시차(staggered)로 식별한다. 조합별 고유 추적 코드 발급. 검정력 미달 신호는 제외하고 사유를 보고한다.
3. **브리프 생성** — 소구점 × 커뮤니티 맥락 결합(온톨로지가 아니라 이 시점에 일어남), 금지 표현·협찬 고지·추적 코드 포함.
4. **신호 수집** — 선행(검색 리프트·코드 첫 구매·PX 셀스루) / 후행(재구매·후기). 예선은 모의 어댑터, 실서비스는 온톨로지의 `acquisition` 필드에 명시된 경로(위탁판매 정산 리포트, 부대별 발주량 프록시, 추적 코드 집계)로 어댑터만 교체한다.
5. **이중 루프** — 주간: 선행 신호로 조합(크리에이터×커뮤니티×제품) 스코어를 EMA 갱신하고 원당 기대 성과 기준으로 예산 재배분(탐색 슬롯 1명 포함). 분기: 도착한 재구매와 선행 신호의 상관(유의성 게이트 + 표본 비례 수축)으로 선행 가중치를 보정한다. 크리에이터 귀속이 불가능한 커뮤니티 단위 신호는 검정을 보류한다(`acquisition.granularity` 기준).

## 정보가 부족하거나 안 풀리는 상황

추측하지 않고 "판단 불가 + 필요한 데이터/조치"를 보고하는 것이 전 단계의 원칙이다.

- 처치/대조 쌍을 만들 수 없는 지점 → 해당 쌍 제외, 사유를 증거 패키지에 명시
- 배정 쌍 수 < 신호의 `min_sample`(검정력 미달) → 해당 신호 제외 + 필요한 데이터 보고
- 시딩 가능(영리 활동 허용) 크리에이터 없음 / 예산 내 선정 가능 후보 없음 → 실행 거부(exit 2)
- 브랜드 안전성 플래그 크리에이터 → 자동 배정 제외, 인간 판단 대기 목록으로 분리
- 분기 보정 표본 부족(재구매 3건 미만) 또는 신호 무변동 → 가중치 유지, 판정 보류 보고

## 실행 (데모)

```bash
# 정상 시나리오: 4주 회전(소모 주기 8배 압축) — 시차 게시 누적, 리프트 검출, 분기 보정까지
python3 src/skills/medi-agent/scripts/pipeline.py --state-dir /tmp/demo --weeks 4 --compress 8

# 예외 시나리오 1: 예산 내 선정 가능한 크리에이터 없음 → 판단 불가 보고, exit 2
python3 src/skills/medi-agent/scripts/pipeline.py --state-dir /tmp/demo_ex1 --budget 5000

# 예외 시나리오 2: 적대 데이터(처치/대조 배정 전면 불가) → 지점 신호 없이 강등 진행

  --data src/skills/medi-agent/data/mock/mock_data_edge.json

# 효과 없는 데이터 → '효과 없음' 보고(오검출 없음)

# 검증 하네스: 인과 검출·CPA 학습곡선·프록시 보정 실측 (시드 5개, 리포트 생성)
python3 src/skills/medi-agent/scripts/verify_harness.py

# 테스트 스위트: 결정 커버리지 + 브랜치 커버리지 실측

```

## 검증 (문항 5와 동일)

검증 대상은 "예측이 맞는가"가 아니라 "루프가 학습하는 구조인가"다. 모의 캠페인(30명×12단위, 소모 주기 8배 압축)을 시드 5개로 반복 실측했다. 수치는 `src/skills/medi-agent/data/verification/report.md`.

1. **인과 검출** — 효과 심은 데이터에서 처치/대조 리프트 검출 5/5, 효과 없는 데이터에서 오검출 0/5.
2. **CPA 학습곡선** — 배치당 전환 비용 1회전 37,747원 → 3회전 2,880원 수렴. 학습을 끈 무작위 선정 베이스라인 대비 +2.8% 개선(같은 시드의 반사실 비교가 학습의 증거).
3. **프록시 보정** — 선행 신호와 재구매의 상관을 일부러 심으면 가중치 0.35→0.50 상승, 끊으면 0.35→0.13 하강. 방향 정답 9/10.
4. **정직성** — 신호·후보·예산 부족 상황에서 추측 없이 판단 불가 보고(위 예외 시나리오로 재현 가능).

검증 도구 자체도 검증했다: 같은 정상 데이터만 반복하면 새 결함을 못 잡으므로(살충제 패러독스) 적대 데이터셋을 별도로 두고, 시스템의 24개 결정을 참/거짓 양방향으로 실행하는 결정 커버리지 스위트로 세 모듈의 브랜치 커버리지 100%를 실측 유지한다. 첫 하네스 실행은 실패였고, 그 실패가 루프 결함 3건(비용 무시 선정, 상관 클리핑 비대칭, 커뮤니티 신호의 크리에이터 귀속 교란)의 수정으로 이어졌다.

## 정직한 한계 (실서비스 갭)

- **모든 수치는 모의 어댑터 위의 결과다.** 숨은 실효과를 심고 신호만 노출하는 구조라 "루프가 학습하는 구조"는 증명되지만, 실제 시장의 효과 크기·노이즈는 다르다.
- **PX 지점별 셀스루의 직접 확보는 미보장.** 위탁판매 정산(품목별 전국·월별)은 확보가 확실하나, 지점별 데이터는 부대별 발주량 프록시(낮은 재고율 가정) 또는 국군복지단 협의(전례 있음, 협상 조건부)에 의존한다 — 온톨로지 `acquisition.confidence`에 등급으로 명시했다.
- **재구매는 소모 주기(1~3개월)만큼 늦게 확정된다.** 주간 루프는 선행 신호로 돌고, 그 예측력 자체를 분기마다 검증하는 이중 루프로 대응했다(데모는 8배 압축).
- 시스템은 PX 입점을 전제하지 않으며(미취급 지점은 검색·코드 신호만 측정), 군 대상 마케팅의 규제·정서 리스크는 브리프 가드레일(협찬 고지 의무, 금지 표현)로 1차 대응한다.
- 밴딧은 정식 Thompson 샘플링이 아니라 EMA + 원당 성과 비례 배분 + 탐색 슬롯의 단순화이고, 시차 식별의 커뮤니티 귀속은 전국 도달 균등 가정을 쓴다.
